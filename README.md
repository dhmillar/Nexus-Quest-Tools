# AutoTrack for WoW Forever

AutoTrack adds automatic quest tracking, a reusable named-target macro, the Rank Quest tracker, and an optional dungeon map view for World of Warcraft: Forever.

## Install and update

- **WowUp:** Select your **WoW Forever** client, open **Get Addons → Install from URL**, and paste https://github.com/dhmillar/AutoTrack.
- **Manual:** Download the versioned ZIP from [Releases](https://github.com/dhmillar/AutoTrack/releases/latest) and extract the included AutoTrack folder into Forever's Interface/AddOns directory. Do not use GitHub's autogenerated Source code ZIP.
- In WoW, use /reload after updating and click the AutoTrack minimap button to open settings.

## Features

- **General:** Automatic quest focus, completion cleanup, and route guidance.
- **Auto Macro:** A reusable exact-name target macro with optional markers and pings on a real keypress.
- **Rank Quest:** Party progress, dungeon/zone grouping, turn-in details, and whole-log search.
- **Dungeon Position:** Opens the matching dungeon map first inside an instance. Uses supported game art or references the installed ForeverDungeonJournal addon. Restricted and wrong-floor coordinates are never shown; no third-party map artwork is distributed.

See the [addon changelog and controls](AutoTrack/README.md) for details.

## Release packaging

Set the version in AutoTrack/AutoTrack.toc, run tools/New-Release.ps1 from PowerShell, and attach the resulting ZIP to a tagged GitHub release of that version. The ZIP contains AutoTrack/AutoTrack.toc at its root folder. There are no paid build steps.
