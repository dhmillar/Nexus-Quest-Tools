# Nexus Quest Tools for WoW Forever

<img src="assets/nexus-fire-cat.png" alt="Nexus Quest Tools fire-cat icon" width="112">

Formerly Rankor Tools and Auto Track. Nexus Quest Tools adds automatic quest tracking, a reusable named-target macro, Rank Quest, and an optional dungeon map view for World of Warcraft: Forever.

## Install and update

- **WowUp:** Select WoW Forever, choose Get Addons > Install from URL, and paste https://github.com/dhmillar/Nexus-Quest-Tools.
- **Manual:** Download the Forever ZIP from [Releases](https://github.com/dhmillar/Nexus-Quest-Tools/releases/latest). Extract the AutoTrack folder into Forever's Interface/AddOns directory. Do not use GitHub's autogenerated source ZIP.
- **Existing users:** Keep the AutoTrack folder name. Your settings, /at command, character macros and keybinds stay in place. Restart WoW if it was running during the update.

Type `/nqt` to open settings. The existing `/at` and `/autotrack` commands still work.

## Features

- **General:** Automatic quest focus, completion cleanup, and route guidance.
- **Auto Macro:** Named-target macro with optional markers and pings on a keypress.
- **Rank Quest:** Party progress, dungeon and zone grouping, turn-in details, and whole-log search. Optional leftover-item badges in Blizzard bags explain why a verified item is not needed by the current log. They never delete items.
- **Dungeon Position:** Matching floor art from the client or an installed Dungeon Journal. Shows only coordinates exposed by WoW on supported floors; no third-party map art is bundled.

See the [addon changelog and controls](AutoTrack/README.md).

## Release packaging

Set the version in AutoTrack/AutoTrack.toc, run tools/New-Release.ps1, and attach the resulting -forever.zip to a tagged GitHub release. The ZIP contains AutoTrack/AutoTrack.toc at its root folder and targets Forever interface 16001.
